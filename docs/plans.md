## レイヤー
- [x] 自分のレイヤーが2枚あって、切り替えられる。
  - [x] 数字の1,2キーでレイヤを切り替えられる
  - [x] 描画ツールは現在のレイヤーに適用される。
  - [x] 現在のレイヤーが Infoのツールの手前に表示される。
