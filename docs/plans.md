## ドラッグで線を描く

- [x] マウスの左ボタンを押して動かすと、点列を取得できる。
- [x] ストロークコマンドにディスパッチするルーターがある
  - [x] canvasとイベントはイベントルーターで一次受け
- [x] 点列をコマンドオブジェクトに記録できる。
- [x] コマンドオブジェクトに基づいて描画される。

- [x] 現在のコマンドをコマンドキューで管理する。

- [ ] 線はドラッグ中もリアルタイムで描画される。
  - [ ] ストロークは、線分ごとにLine関数を呼ぶように修正。
  - [ ] 本物のLine関数は、RenderTextureへの焼き込みで作る
  - [ ] テストダブルのLine関数を作る。
  - [ ] マウスUPした座標は記録されない。

- [x] 色計算のヘルパーを追加

- [x] Layerはidを返す
- [x] LayerはGraphcisオブジェクトを返す。
